Что запущено

  • web — этот сайт, Apache httpd 2.4 в контейнере;
  • db — СУБД MySQL 8.0 с базой notes;
  • app — собственное приложение на Flask, пишет и читает записи в MySQL;
  • backup — контейнер, который по расписанию делает дампы базы.

Ниже форма: она отправляет POST-запрос на /api/notes. Apache проксирует его в контейнер приложения, а тот сохраняет запись в MySQL.
