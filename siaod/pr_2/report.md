# Ход работы

## Постановка задачи

Вариант 3: создать приложение для хранения студентов. Поля записи — номер зачётной книжки, номер группы и ФИО; ключ — номер зачётной книжки. Реализовать вставку, поиск, удаление и вывод с помощью открытой адресации и двойного хеширования.

## Математическая модель

Полезные данные находятся в динамическом массиве. Ячейка хеш-таблицы содержит ключ, состояние и индекс записи в этом массиве. Для размера таблицы `m` и байтов ключа рассчитываются полиномы `P₃₁` и `P₃₇`: на каждом шаге `P = (P × основание + байт) mod 2⁶⁴`. Далее:

```text
h1 = P₃₁ mod m
h2 = 1 + P₃₇ mod (m - 1)
адрес пробы i = (h1 + i × h2) mod m
```

Размер `m` — простое число, поэтому шаг `h2` взаимно прост с ним и пробы обходят всю таблицу. Удалённая ячейка помечается отдельно: поиск через неё продолжается. Перед вставкой при превышении нагрузки 0,7 таблица увеличивается и рехешируется; при большом числе меток удаления возможна перестройка в прежнем размере.

Полные исходные тексты с комментариями: [класс и структуры](include/student_hash_table.hpp), [хеш-таблица](src/student_hash_table.cpp), [командный интерфейс](src/main.cpp). Ниже приведён фрагмент поиска: он использует двойное хеширование и не останавливается на метке удаления.

```cpp
std::optional<std::size_t> StudentHashTable::findSlot(std::string_view key) const {
    const std::size_t m = table_.size();
    std::size_t position = primaryHash(key, m);
    const std::size_t step = secondaryHash(key, m);

    for (std::size_t probe = 0; probe < m; ++probe) {
        const Slot& slot = table_[position];
        if (slot.state == State::empty) {
            return std::nullopt; // За никогда не занятой ячейкой ключа нет.
        }
        if (slot.state == State::occupied && std::string_view(slot.key) == key) {
            return position;
        }
        // Метка удаления не прерывает последовательность проб.
        position = nextProbe(position, step, m);
    }
    return std::nullopt;
}
```
