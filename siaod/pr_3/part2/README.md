# Практическая работа №7.2 — Графы, кратчайший путь деревом решений (вариант 3)

## Вариант

- **Алгоритм:** нахождение кратчайшего пути методом построения дерева решений
- **Граф:** предложенный ориентированный взвешенный граф из 6 вершин (вариант 3)

## Структура

| Путь | Назначение |
|---|---|
| `include/graph.hpp` | Структуры графа и дерева решений |
| `src/graph.cpp` | Представление графа, алгоритм поиска, предложенный граф |
| `src/main.cpp` | Консольное меню, ввод произвольного графа |
| `tests/graph_tests.cpp` | Автоматические тесты |
| `CMakeLists.txt` | Сборка CMake |
| `report.md` | **Полный отчёт и пояснение**: постановка, алгоритм, архитектура, сравнение алгоритмов, тесты, ответы на контрольные вопросы |

## Сборка и запуск

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
./build/pr3_part2 --demo
```

Без CMake:

```bash
g++ -std=c++17 -Wall -Wextra -Wpedantic -Iinclude src/graph.cpp src/main.cpp -o pr3_part2
./pr3_part2 --demo
```

Тесты:

```bash
g++ -std=c++17 -Wall -Wextra -Wpedantic -Iinclude src/graph.cpp tests/graph_tests.cpp -o graph_tests
./graph_tests
```

## Что читать

Для защиты/понимания работы откройте `report.md` — там описано что сделано, как устроен граф, как работает метод дерева решений, пошаговый разбор, сравнение с Дейкстрой/Беллманом-Фордом/Флойдом, ответы на контрольные вопросы.
